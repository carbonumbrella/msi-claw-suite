# MSI Claw Suite

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live-brightgreen)](https://carbonumbrella.github.io/msi-claw-suite/en/)

Technical knowledge base, calibration portal, and open-source utility ecosystem for MSI Claw handheld gaming PCs (MSI Claw 8 AI+, Claw 7 AI+, and Claw A1M).

## Core Capabilities

- **16:10 Custom Resolutions:** Calibrated intermediate resolutions (1600x1000 at 1.20x and 1536x960 at 1.25x / 80%) designed for temporal upscalers (XeSS, FSR, TAAU) while preserving native DisplayID 2.0 VRR (48 to 120 Hz).
- **Windows 11 OS Cleanup:** Reclaiming system RAM for the Intel Arc shared video buffer (reducing background Windows footprint from >5.7 GB to 3.5 GB), removing 28 local AI packages, and mapping Modern Standby to S4 hibernation.
- **Hardware Ecosystem Utilities:**
  - **SaySo:** Local voice dictation and agent execution running on Intel Lunar Lake NPU via OpenVINO.
  - **ClawAmbilight:** Real-time analog stick Ambilight rendered on GPU with near-zero CPU overhead.
  - **kbdhaptic:** Keyboard haptic feedback engine and screen auto-rotation fix.

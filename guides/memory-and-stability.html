Оптимизация памяти, файл подкачки и стабильность системы на MSI Claw

Архитектура объединенной памяти LPDDR5x, предотвращение сбоев DirectX через фиксацию 16 ГБ pagefile и нюансы безопасности ядра Windows 11.

Устройства: MSI Claw 8 AI+, Claw 7 AI+, Claw A1M
Память: 32 ГБ LPDDR5x
Время чтения: 7 минут

1. Объединенная архитектура памяти LPDDR5x

В процессорах Intel Core Ultra 200V (Lunar Lake) применена архитектура Memory on Package (MoP): кристаллы сверхскоростной оперативной памяти LPDDR5x (скорость до 8533 МТ/с) распаяны непосредственно на процессорной подложке. Это обеспечивает минимальные физические задержки и широкую шину обмена данными.

Вся оперативная память устройства является полностью объединенной: физический массив разделяется между ядрами процессора (CPU), графическим ускорителем Intel Arc (GPU) и нейронным сопроцессором (NPU).

2. Распределение памяти GPU в Windows и драйвере Intel Arc

На платформе MSI Claw нет необходимости настраивать параметры памяти в BIOS: в процессорах Intel Core Ultra (Lunar Lake) оперативная память LPDDR5x является полностью объединенной, а в заводской прошивке отсутствует классический переключатель кадрового буфера (UMA Frame Buffer).

Управление памятью осуществляется операционной системой Windows 11 и графическим драйвером Intel Arc динамически. По спецификации Windows Display Driver Model (WDDM), графической подсистеме автоматически предоставляется до половины от общего объема физической памяти устройства.

На консоли с 32 ГБ памяти это означает, что графический процессор Intel Arc гарантированно получает доступ к 16 ГБ общей видеопамяти (Shared GPU Memory). Этого объема с запасом хватает любым современным играм под текстурные пакеты высокого разрешения без каких-либо манипуляций с BIOS.

Контроль параметров памяти в Windows: Фактическое состояние видеобуфера отображается в реальном времени: в «Диспетчере задач» (комбинация клавиш Ctrl + Shift + Esc) на вкладке «Производительность» в разделе «Графический процессор» параметр «Общая память GPU» составляет 16,0 ГБ.

3. Фиксированный файл подкачки (Pagefile) 16 ГБ

После того как видеочип забирает под свои нужды от 8 до 16 ГБ, объем физической памяти, оставшийся для самой операционной системы Windows 11 и фоновых служб, существенно сокращается.

В стандартной конфигурации Windows использует динамический файл подкачки с параметром «По выбору системы». Когда игра внезапно требует дополнительную память под системные библиотеки, Windows начинает срочно увеличивать размер файла на накопителе SSD прямо во время геймплея.

Причина фатальных сбоев DirectX (DXGI): Операция расширения файла подкачки на диске вызывает мгновенный всплеск задержки ввода-вывода (I/O latency). Графический конвейер игры не успевает получить ответ от системного диспетчера памяти за отведенный таймаут и падает с ошибками DXGI_ERROR_DEVICE_REMOVED, DXGI_ERROR_DEVICE_HUNG или Out of Video Memory, хотя физически память еще доступна.

Решение: статическая фиксация на 16384 МБ

Автоматическая фиксация: Фиксация статического файла подкачки 16 ГБ (16384 МБ), отключение автоматического управления Windows и очистки файла при выключении выполняются автоматически в скрипте Optimize-Handheld (категория Memory).

Фиксация файла подкачки (исходный и максимальный размер одинаковы и равны 16 ГБ) заставляет Windows сразу выделить единый нефрагментированный контейнер на быстром SSD PCIe 4.0. Системе больше никогда не требуется менять его размер на лету.

Выполните команду в PowerShell от имени администратора: 

Set-CimInstance -Query "Select * from Win32_PageFileSetting where Name like 'C:%'" -Property @{InitialSize = 16384; MaximumSize = 16384}

Либо через графический интерфейс:

  1. В окне «Выполнить» (Win + R) введите sysdm.cpl.
  2. Вкладка «Дополнительно» → графа «Быстродействие» → кнопка «Параметры».
  3. Вкладка «Дополнительно» → блок «Виртуальная память» → кнопка «Изменить».
  4. Снимите галочку «Автоматически выбирать объем файла подкачки».
  5. Выберите диск C:, отметьте пункт «Указать размер»: Исходный размер: 16384, Максимальный размер: 16384.
  6. Нажмите кнопку Задать, затем ОК и перезагрузите устройство.

4. Выбор софта для управления консолью

На портативном ПК с объединенной памятью LPDDR5x и строгим теплопакетом выбор управляющего софта напрямую влияет на стабильность кадров. Тяжелые фоновые службы отбирают оперативную память у видеокарты, а непрерывный опрос датчиков может забивать шину управления.

5. Безопасность ядра (HVCI) и оптимизация служб

Изоляция ядра (Memory Integrity / HVCI)

Функция изоляции ядра (Hypervisor-Protected Code Integrity) в Windows 11 изолирует критические процессы памяти в виртуализированной среде. Некоторые низкоуровневые модули управления лимитами процессора и доступом к портам MSR могут блокироваться этой подсистемой.

Если утилиты управления консолью выдают ошибку доступа к низкоуровневому драйверу: откройте приложение «Безопасность Windows» → «Безопасность устройства» → «Сведения об изоляции ядра» и отключите тумблер «Целостность памяти», после чего перезагрузите систему.

Остановка фоновых аудиоэффектов

Пакет Optimize-Handheld отключает неиспользуемые фоновые службы пространственного звука Nahimic и Realtek Audio Effects. Это освобождает до 250 МБ оперативной памяти и убирает лишние циклы постобработки аудиосигнала, снижая общую нагрузку на процессорные ядра.

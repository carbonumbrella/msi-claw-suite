Операционная система и архитектура

Оптимизация памяти, файл подкачки и стабильность системы

Архитектура LPDDR5x, статический pagefile 16 ГБ против вылетов DirectX, службы Windows 11, EC Reset и BIOS.

Устройства: MSI Claw 8 AI+, Claw 7 AI+, Claw A1M
Память: 32 ГБ LPDDR5x
Время чтения: 7 минут

1. Объединенная память LPDDR5x

Процессор Intel Core Ultra 200V (Lunar Lake) использует архитектуру Memory on Package (MoP): память LPDDR5x (до 8533 МТ/с) распаяна на подложке и динамически разделяется между CPU, ГПУ Intel Arc и NPU.

2. Память GPU в Windows и драйвере Intel Arc

Переключателя UMA Frame Buffer в BIOS нет: по стандарту WDDM система выделяет до 50% ОЗУ под видеопамять (16,0 ГБ Shared GPU Memory на 32 ГБ консоли; в Intel Graphics Software также доступен ползунок Shared GPU Memory Override с базовым пределом 57% ~18,2 ГБ). Этого хватает любым играм без правки BIOS.

Проверить фактический пул: «Диспетчер задач» (Ctrl + Shift + Esc) → «Производительность» → «Графический процессор» → строка «Общая память GPU» (16,0 ГБ по умолчанию).

3. Фиксированный файл подкачки 16 ГБ

Когда видеоядро занимает 8..16 ГБ, остаток ОЗУ под ОС сокращается. При динамическом pagefile («По выбору системы») Windows расширяет файл на SSD прямо в игре, вызывая всплеск задержек I/O.

Причина вылетов DirectX (DXGI): во время расширения pagefile драйвер ГПУ не укладывается в таймаут и выдает DXGI_ERROR_DEVICE_REMOVED, DXGI_ERROR_DEVICE_HUNG или Out of Video Memory.

Фиксация 16384 МБ (вручную или через Optimize-Handheld)

Категория Memory в Optimize-Handheld автоматически фиксирует 16 ГБ (16384 МБ) и отключает очистку файла при выключении.

Вручную через PowerShell от имени администратора:

Set-CimInstance -Query "Select * from Win32_PageFileSetting where Name like 'C:%'" `
  -Property @{InitialSize = 16384; MaximumSize = 16384}

Через интерфейс Windows:

  1. Нажмите Win + R, введите sysdm.cpl → «Дополнительно» → «Быстродействие» («Параметры») → «Дополнительно» → «Виртуальная память» («Изменить»).
  2. Снимите галочку автовыбора, выберите диск C:, задайте исходный и максимальный размер 16384, нажмите Задать → ОК и перезагрузите консоль.
Каждые 300:500 МБ фонового ПО отнимают память у ГПУ и ускоряют свопинг. Сравнение утилит: Выбор софта →.

4. Изоляция ядра (HVCI), аудиослужбы и BitLocker

  • Изоляция ядра (HVCI): при ошибках доступа утилит к драйверам MSR/TDP откройте «Безопасность Windows» → «Безопасность устройства» → «Сведения об изоляции ядра», выключите «Целостность памяти» и перезагрузите консоль.
  • Фоновые аудиослужбы: опциональная категория VendorAudio в Optimize-Handheld отключает сторонние службы обработки звука DTS (DtsApo4Service) и MSI intelliGo (IgoAudioService) (~90 МБ ОЗУ и фоновые циклы ЦП), не затрагивая базовый аудиодрайвер Realtek.
  • Шифрование устройства (BitLocker): включенное по умолчанию шифрование грузит ЦП и контроллер SSD при подгрузке ассетов. Отключите через опцию 6 в Optimize-Handheld или в «Параметры» → «Конфиденциальность и безопасность» → «Шифрование устройства».

5. Сброс контроллера питания (EC Reset) и вход в UEFI

Аппаратный EC Reset (при зависании или черном экране):
  1. Удерживайте кнопку питания 20-30 секунд до полного погасания всех индикаторов и подсветки стиков.
  2. Плата перейдет в режим защиты Shipping Mode: без зарядки консоль не включится.
  3. Подключите штатный блок питания Type-C и нажмите кнопку питания один раз.

Вход в BIOS / UEFI:

  • Кнопками геймпада: на выключенной консоли зажмите RB + RT и нажмите питание (работает при отключенном Fast Boot в BIOS).
  • Через Windows: «Параметры» → «Система» → «Восстановление» → «Расширенный запуск» → «Перезагрузить сейчас» → «Поиск и устранение неисправностей» → «Дополнительные параметры» → «Параметры встроенного ПО UEFI».
  • С внешней клавиатуры: нажимайте Del или F2 при старте.

6. Скрытое сервисное меню BIOS

Right Ctrl + Right Shift + Left Alt + F2
  • Только проводная USB-клавиатура (или 2.4 ГГц донгл): Bluetooth-клавиатуры до загрузки Windows не работают.
  • Риск бутлупа: правка таймингов памяти и VRAM в скрытом меню на Lunar Lake не дает прироста и часто вызывает циклический bootloop; памятью управляeт микрокод Intel и драйвер Arc.

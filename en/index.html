Custom 16:10 Resolutions (1600x1000 and 1536x960)

Intermediate modes with clean 1.20x and 1.25x scaling ratios reduce GPU shading workload without subpixel distortion.

1600x1000 (1000p) Exact 1.20x Ratio
1920 / 1.20 = 1600 | 1200 / 1.20 = 1000

Alternative to standard 1050p (1680x1050). The 1.20x multiplier eliminates sampling errors, matching 1200p clarity while cutting GPU shading load by 30.5%.

  • Intermediate step between 1200p and 900p
  • 30.5% reduction in processed pixel count
  • Clean 1.20x step for temporal upscalers
  • Native 16:10 aspect ratio without letterboxing
1536x960 (960p) Exact 1.25x Ratio (80%)
1920 * 0.80 = 1536 | 1200 * 0.80 = 960

Alternative to standard 900p (1440x900). Exactly 80% of native panel resolution horizontally and vertically. The clean 1.25x multiplier aligns with the pixel grid for Intel XeSS and AMD FSR reconstruction.

  • 36% reduction in GPU fillrate workload
  • Crisp text and HUD elements without blur
  • Clean 1.25x (80%) ratio for reconstruction algorithms
  • Full support for 120 Hz and VRR 48:120 Hz range
Both Modes Coexist Simultaneously: 1600x1000 and 1536x960 are added alongside existing system resolutions. They are immediately selectable in Windows Display Settings, inside in-game menus, and in the ClawTweaks Game Bar dropdown.

Windows Debloat & Tuning: Optimize-Handheld

Safe, modular Windows 10/11 optimization suite designed specifically for handheld gaming PCs. Derived strictly from real-world telemetry logs of the MSI Claw 8 AI+.

Standard Level

Core Optimization

Safe baseline for all handheld users. Disables components unnecessary on a dedicated gaming device.

  • • Removal of background AI packages (Recall, Copilot)
  • • Disabled telemetry tasks and DiagTrack service
  • • S4 Hibernation: S0 standby disabled, timeouts (10m DC / 60m AC), buttons to hibernate
  • • Static 16 GB pagefile on C: to prevent DXGI DirectX crashes
  • • Hardware GPU scaling set to Maintain Aspect Ratio via CCD API
  • • Touch keyboard on login screen (DisableAutomaticRestartSignOn)
Full Level

Deep Resource Freeing

Includes Standard level plus unloaded secondary background tools and sync services.

  • • Blocked OneDrive background file sync
  • • Unloaded Intel DSA background updater service
  • • Stopped unused background audio processing effects
  • • Removed deprecated Windows components (WMIC, Media Player, Phone Link)
Check Savings Mode

Objective Measurement

Built-in audit function to measure verified resource savings without administrator rights.

  • • Measurement of reclaimed system RAM
  • • Tally of freed SSD storage space
  • • List of eliminated background processes
  • • Before/after state comparison against baseline
Gaming Stack Protection: The script enforces a strict whitelist and will never touch or remove Xbox, Game Bar, Gaming Services, Microsoft Store, Windows Defender, GPU drivers, or handheld management tools (MSI Center M, ClawTweaks, HidHide). Every action supports full reversal via Undo.

Dedicated Utilities for MSI Claw

Software solutions engineered specifically around the hardware features of the Claw platform.

Whisper int8 • Intel NPU • Push-to-Talk

SaySo: Voice Assistant & Dictation

Voice assistant and dictation daemon running locally on the integrated Intel NPU (Lunar Lake). Enables hands-free text input into any game chat or app field by holding a controller paddle, alongside voice-driven hardware control.

  • Fast speech-to-text with spoken correction ("delete word", "replace with") without cloud latency
  • Direct TDP power adjustments, fan curves, and game pausing via ClawTweaks integration
  • Automatic mapping to rear M1 and M2 paddles, with per-game profile awareness
  • Responsive C# WPF UI that re-flows into a single column in vertical screen orientation
SaySo Repository on GitHub
Direct HID • DXGI Desktop Duplication • GPU Averaging

ClawAmbilight: Dynamic Stick Lighting

Adaptive LED ring lighting for analog sticks and ABXY buttons reactive to on-screen game colors. Frames are captured via DXGI Desktop Duplication and averaged directly on the GPU shader core, consuming only ~1.5% of one CPU core without impacting game framerates.

  • Soft (subtle ambient scene colors) and Vivid (dynamic high-brightness accents) modes
  • Joy-Con preset inspired by classic neon blue and neon red Nintendo Switch palettes
  • Direct HID vendor 0x0F report writes into controller RAM without flash memory wear
  • Automatic frame polling drop and LED update throttle when switching to battery power
ClawAmbilight Repository on GitHub
XInput Haptics • WinRT Reflection • Auto-Rotate

kbdhaptic: Haptic Typing & Auto-Rotation

Addresses two hardware quirks of Windows 11 handhelds: delivers tactile motor feedback from built-in rumble motors on touch keyboard typing, and restores functional screen auto-rotation.

  • Crisp XInput motor pulses on each screen keystroke via IFrameworkInputPane notification
  • File Explorer navigation using gamepad buttons (A: open, B: back, Y: up, X: context menu)
  • Bypasses Simple Device Orientation limitations via WinRT sensor polling and ChangeDisplaySettingsEx
  • Synchronized with the native Windows Quick Settings Auto-Rotate toggle button
kbdhaptic Repository on GitHub

Touch Keyboard on Lock Screen

Disabling Automatic Restart Sign-On (ARSO) policy via Windows Registry. Prevents the on-screen touch keyboard from abruptly collapsing when entering PIN on the lock screen.

Unlocking the Upper Fan Curve

Enabling Extended range >75 in the ClawTweaks Fan tab and setting the top two curve points (80°C and 88°C) to 85% and 120% to prevent thermal throttling under sustained load.

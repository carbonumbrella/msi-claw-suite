Custom 16:10 Resolutions (1600x1000 and 1536x960)

Clean 1.20x and 1.25x modes replace fractional 1050p and 900p, reducing GPU load without blur.

1600x1000 (1000p) Exact 1.20x Ratio
1920 / 1.20 = 1600 | 1200 / 1.20 = 1000

Alternative to 1680x1050. Near-native 1200p sharpness with 30.5% lower GPU workload.

  • Intermediate step between 1200p and 900p
  • GPU pixel workload: -30.5%
  • 1.20x step for temporal upscalers
  • 16:10 aspect ratio without black bars
1536x960 (960p) Exact 1.25x Ratio (80%)
1920 * 0.80 = 1536 | 1200 * 0.80 = 960

Alternative to 1440x900: exactly 80% of 1200p, matching Intel XeSS and AMD FSR pixel grids.

  • GPU pixel workload: -36%
  • Crisp text and UI without blur
  • 1.25x (80%) multiplier for upscalers
  • Full 120 Hz and VRR 48:120 Hz support
Both Modes Together: 1600x1000 and 1536x960 are added simultaneously and appear in Windows, games, and the ClawTweaks quick menu.

Windows Debloat & Tuning: Optimize-Handheld

Windows 10/11 tuning script built strictly from the MSI Claw 8 AI+ system ledger.

Standard Level

Core Optimization

Safe baseline: removes bloatware while keeping the gaming stack untouched.

  • • Removal of Recall and Copilot packages
  • • Disabled telemetry and DiagTrack service
  • • S4 Hibernation: S0 disabled, timeouts (10m DC / 60m AC), buttons to hibernate
  • • Static 16 GB pagefile (16384 MB) preventing DXGI crashes
  • • GPU Maintain Aspect Ratio scaling
  • • Lock screen touch keyboard (ARSO fix)
Full Level

Deep Resource Freeing

Standard plus secondary background services and legacy apps.

  • • Blocked OneDrive background sync
  • • Disabled Intel Graphics and Logitech Options+ startup (plus optional Intel DSA and DTS/intelliGo audio)
  • • Removed WMIC, Media Player, Phone Link, and Maps
Check Savings & BitLocker

Audit & Encryption

Non-admin resource comparison and BitLocker decryption.

  • • Reclaimed RAM and SSD space metrics
  • • List of eliminated background processes
  • • Option 6: BitLocker decryption on C:
Whitelist Protection: Never modifies Xbox, Game Bar, Gaming Services, Microsoft Store, Defender, GPU drivers, MSI Center M, ClawTweaks, or HidHide. Every step is reversible via Undo.

Dedicated Utilities for MSI Claw

Open-source tools built specifically for Claw hardware.

Whisper • Intel NPU • Push-to-Talk

SaySo: Voice Assistant & Dictation

Local voice dictation and commands on Intel NPU (small int8 default, optional large-v3-turbo fp16).

  • Hold-to-talk dictation with voice edits ("delete word", "replace with") without cloud latency
  • TDP, fan, and game pause control via ClawTweaks integration
  • M1/M2 paddle binding and per-game profiles
  • Bilingual UI (EN / RU) with automatic Windows language detection
SaySo Repository on GitHub
HID 0x0F • DXGI Desktop Duplication • ~1.5% CPU

ClawAmbilight: Dynamic Stick Lighting

Screen-reactive LED lighting for stick rings and ABXY via DXGI and GPU mipmap averaging (~1.5% of one CPU core).

  • Ambient, Vibrant, Buttons Only, and Joy-Con preset modes
  • Direct HID 0x0F RAM writes with zero flash wear
  • Eco battery polling and bilingual UI (EN / RU)
ClawAmbilight Repository on GitHub
XInput Haptics • WinRT • Auto-Rotate

kbdhaptic: Haptic Typing & Auto-Rotation

Adds tactile rumble feedback for touch keyboard typing and restores screen auto-rotation on Windows 11.

  • XInput motor pulses per keystroke via IFrameworkInputPane
  • Explorer gamepad navigation (A: open, B: back, Y: up, X: menu)
  • Auto-rotation via WinRT Simple Device Orientation and ChangeDisplaySettingsEx synced with Windows Auto-Rotate lock
  • Bilingual UI (EN / RU)
kbdhaptic Repository on GitHub
ControlLib.dll • D3DKMT • 48..120 Hz • 0% Background

ArcSyncSwitch: Intel Arc Sync & LFC Profiles

Switches Intel VRR and LFC profiles: lifts the 60..120 Hz clamp to unlock hardware 48..120 Hz without EDID changes.

  • Switches driver to EXCELLENT (48..120 Hz) via ControlLib.dll
  • Preserves custom 1600x1000 and 1536x960 resolutions
  • Independent LFC flag toggling via D3DKMTEscape
  • Silent logon task (--apply) with zero background process
  • Bilingual UI (EN / RU)
ArcSyncSwitch Repository on GitHub

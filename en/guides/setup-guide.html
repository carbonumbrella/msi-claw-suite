Step-by-Step Setup Guide for MSI Claw: From Clean Windows 11 to Gaming

Systematic deployment order: hardware drivers, MSI Center M firmware updates, unlocking the 75% fan ceiling, ClawTweaks configuration, Windows debloating, and 16:10 custom resolutions.

Hardware: MSI Claw 8 AI+, Claw 7 AI+, Claw A1M
Memory: 32 GB LPDDR5x
Estimated Time: 15-20 minutes
Select Your Starting Point:
  • Factory Installed Windows: If your console runs the factory OEM image, skip Steps 1 and 2. Start directly at Step 3 (Windows Updates).
  • Fresh Clean Installation: If installing Windows 11 from a bootable USB drive onto a clean SSD, follow all steps in order starting with Step 1.

1 Clean Windows 11 Installation (Reinstall Scenario)

If your system came preinstalled: skip this step and proceed directly to Step 3.

Install a clean Windows 11 Home image from a bootable flash drive. The factory digital license key is embedded in motherboard ACPI tables (MSDM), activating automatically upon connection.

Bypassing Network Requirement during OOBE Setup: If Wi-Fi hardware is not recognized out-of-the-box and the setup wizard demands an internet connection, press Shift + F10 (or summon the on-screen keyboard), type oobe\bypassnro and press Enter. The console reboots with an "I don't have internet" option, creating a clean local user account.

2 Core Hardware Drivers & MSI Center M

If using factory Windows: drivers and MSI Center M are already installed. Check for firmware updates via Live Update and proceed to Step 3.

Download official drivers and MSI Center M from the MSI Claw support page.

  • Firmware Updates: Open MSI Center M and run Live Update to flash the latest BIOS and Embedded Controller (EC) microcode. This ensures reliable M1/M2 paddle signaling and updated fan curves.
  • Platform Drivers: Install Chipset, Wi-Fi, Bluetooth, and Audio drivers to resolve all unrecognized Device Manager devices.

3 Windows Update & Xbox Dependencies

Mandatory prerequisites before applying debloat scripts:

  1. Open Windows Settings → Windows Update and install all cumulative updates until no pending items remain.
  2. Open Microsoft Store → Library and click "Get updates".
  3. Ensure packages for Xbox Game Bar, Gaming Services, and Xbox App are completely updated.
  4. Reboot the device.

4 ClawTweaks Widget Installation

Download the handheld control widget from the enterTheVoidCode/ClawTweaks repository.

  • Hardware Invocation Button: The widget runs as an Xbox Game Bar overlay and is summoned by pressing the right hardware Claw button (located below the Menu / Start button).
  • Kernel Isolation: If the widget reports missing access to low-level hardware registers on first run, open Windows Security → Device Security → Core Isolation Details and turn off "Memory Integrity" (HVCI), then reboot.

5 Intel Arc Graphics Driver Installation

Install the latest WHQL Intel Arc Graphics driver package via MSI Center M, Intel Driver Support Assistant, or ClawTweaks.

Installation Order: The GPU driver must be installed prior to custom 16:10 resolution injection. Installing a display driver on top of custom modes overwrites registry override keys.

6 Unlocking the Factory Fan Speed Ceiling

By default, MSI firmware caps fan speeds at 75% across the curve (0°C, 50°C, 60°C, 70°C, 80°C, 88°C). Under prolonged heavy gaming loads, this ceiling causes unnecessary thermal throttling.

  1. Open ClawTweaks (right Claw button) and switch to the Fan Control tab.
  2. At the bottom of the tab, toggle Extended range >75 to allow fan speeds past 75%.
  3. Adjust the top two temperature points (80°C and 88°C) from default 67% and 75% up to 85% and 120%.
  4. Click Apply Fan Curve: the curve writes to the EC controller, securing cooling headroom for higher TDP levels.

7 OS Debloating & Tuning: Optimize-Handheld

Download the handheld debloat package from carbonumbrella/optimize-handheld and launch Optimize-Handheld.ps1 (or Optimize-Handheld.cmd) as Administrator:

  1. Select Standard profile: removes Recall and Copilot packages, disables DiagTrack telemetry.
  2. Configures S4 Hibernation: disables S0 Modern Standby, sets auto-hibernation (10 min battery / 60 min AC), maps power buttons to hibernate, disables wake timers.
  3. Locks the system pagefile to a static 16384 MB (16 GB): eliminates dynamic paging stalls and prevents DirectX DXGI_ERROR_DEVICE_REMOVED crashes.
  4. Applies hardware GPU Maintain Aspect Ratio scaling for non-native resolutions and enables touch keyboard on the login screen (ARSO fix).
  5. Reboot the handheld.

8 16:10 Resolutions (Handheld Resolution Pack)

Inject intermediate 1536x960 (1.25x ratio) and 1600x1000 (1.20x ratio) display modes:

  1. Download the archive from the Downloads section or the handheld-resolution-pack repository, unpack it, and run Run_As_Admin.cmd in folder 1_Universal_Auto (reads active panel EDID, writes overrides, restarts display driver, and patches ClawTweaks).
  2. Restart the graphics driver via Win + Ctrl + Shift + B or reboot the console.
  3. The new modes appear in Windows Display Settings, in-game resolution pickers, and the ClawTweaks Game Bar quick menu.

9 Display Panel Color Calibration (Optional)

The factory panel calibration exhibits a cooler white balance (~7200K). To align with the neutral cinematic sRGB 6500K standard:

  1. Download the verified ICC calibration profile for the MSI Claw panel by Notebookcheck.
  2. Open Run (Win + R) and launch colorcpl.exe.
  3. Select the console panel, click "Add", choose the ICC file, and click "Set as Default Profile".

10 Handheld Background Utilities (Optional)

Open-source utilities available for specific workflows:

  • SaySo: Local NPU voice dictation and hardware controls by holding rear paddles.
  • ClawAmbilight: Real-time screen color stick lighting averaged on the GPU with zero CPU penalty.
  • kbdhaptic: Haptic vibration confirmation on touch keyboard typing and hardware auto-rotation.

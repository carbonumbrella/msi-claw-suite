Deployment Manual

Step-by-Step MSI Claw Setup: From Clean Windows to Gaming

Deployment sequence: Windows 11, drivers and firmware, ClawTweaks, unlocking the 75% fan ceiling, Optimize-Handheld, and 16:10 modes.

Hardware: MSI Claw 8 AI+, Claw 7 AI+, Claw A1M
Memory: 32 GB LPDDR5x
Estimated Time: 15-20 minutes
Select Your Starting Point:
  • Factory Windows: skip Steps 1 and 2; start at Step 3.
  • Clean SSD: follow every step from Step 1.

1 Clean Windows 11 Home Install

Factory image already installed: proceed to Step 3.

Install Windows 11 Home: the license key is embedded in motherboard ACPI (MSDM) and activates automatically. If Wi-Fi fails during OOBE, press Shift + F10, run oobe\bypassnro → Enter, and pick "I don't have internet" after reboot for a local account.

2 Core Drivers & MSI Center M

Factory Windows: verify firmware updates in MSI Center M Live Update and jump to Step 3.

Download MSI Center M plus Chipset, Wi-Fi, Bluetooth, and Audio drivers from MSI support. In MSI Center M Live Update, flash the latest BIOS and EC microcode (required for M1/M2 paddles and fan control).

3 Windows Update & Xbox Dependencies

  1. Settings → Windows Update: install all cumulative updates until none remain.
  2. Microsoft Store → Library → "Get updates": update Xbox Game Bar, Gaming Services, and the Xbox App.
  3. Reboot the console.

4 ClawTweaks Widget Installation

Install enterTheVoidCode/ClawTweaks: it opens over games inside Xbox Game Bar via the right Claw button (below Menu/Start). If register access fails, disable "Memory Integrity" (HVCI) in Windows Security → Device Security → Core Isolation Details, then reboot.

5 Intel Arc Graphics Driver

Install the latest WHQL Intel Arc driver via MSI Center M, Intel tools, or ClawTweaks.

Intel Graphics Software Settings:
  • Shared GPU Memory Override: leave at stock ~57% (50% = 16 GB on the 32 GB model).
  • Low Latency Mode: On for daily/battery play; On + Boost (locks GPU at 1950 MHz) on AC power or with frame generation.
  • Endurance Gaming: active only on battery (60/40/30 FPS caps); disengages on AC.
  • Display Scaling: GPU Scaling + Preserve Aspect Ratio for 16:10.
Order: install the GPU driver BEFORE applying custom 16:10 resolutions, or the installer overwrites EDID registry overrides.

6 Unlocking the 75% Fan Ceiling

MSI factory presets clamp fans at 75% (curve points: 0/50/60/70/80/88°C; details in Power & Fan Curves).

  1. Open ClawTweaks (right Claw button) → Fan Control tab.
  2. Enable Extended range >75 at the bottom.
  3. Raise the top two points (80°C and 88°C) from stock 67% and 75% to 85% and 120%.
  4. Click Apply Fan Curve to write it to the EC controller.

7 OS Optimization: Optimize-Handheld

Download carbonumbrella/optimize-handheld and run Optimize-Handheld.ps1 (or .cmd) as Administrator:

  1. Pick Standard profile: removes Recall/Copilot, disables DiagTrack telemetry.
  2. Switches S0 Modern Standby to S4 Hibernation (0 min sleep timeout, auto-hibernate 10 min battery / 60 min AC, power buttons to hibernate, wake timers off).
  3. Locks a static 16384 MB (16 GB) pagefile against DXGI_ERROR_DEVICE_REMOVED.
  4. Applies GPU Maintain Aspect Ratio scaling and enables the login touch keyboard (ARSO).
  5. Option 6: disables BitLocker encryption (removes background SSD/CPU overhead). Reboot.

8 16:10 Resolutions (Handheld Resolution Pack)

Adds 1536x960 (1.25x) and 1600x1000 (1.20x) (details in Game Tuning):

  1. Download from Downloads or GitHub, extract, and run 1_Universal_Auto\Run_As_Admin.cmd.
  2. The script reads the panel EDID, injects 1600x1000 and 1536x960, automatically restarts the display driver, and patches ClawTweaks (manual Win + Ctrl + Shift + B is only needed if modes do not refresh).
  3. Both resolutions appear in Windows Settings, games, and ClawTweaks.

9 6500K Color Calibration (Optional)

Factory white point measures cool at ~7852K (Notebookcheck). For neutral sRGB 6500K:

  1. Download PN8007QB1_2_cal.icm (26 KB).
  2. Press Win + R → run colorcpl.exe, select the panel → "Add" → "Set as Default Profile".

10 Additional Utilities (Optional)

  • ArcSyncSwitch: switches VRR from 60..120 Hz to native EXCELLENT 48..120 Hz via ControlLib.dll (VRR Guide).
  • OptiClick: one-click OptiScaler deployment for Intel XeSS and XeFG (details).
  • SaySo: local NPU voice dictation and commands (RU/EN) via rear paddles M1/M2.
  • ClawAmbilight: screen-synced thumbstick/button Ambilight (~1.5% CPU load).
  • kbdhaptic: haptic feedback on the touch keyboard and auto-rotation.
External GPUs (eGPU over Thunderbolt 4): do not remove the Intel Arc driver via DDU when plugging in an eGPU over Type-C; Windows 11 coordinates both GPUs cleanly.
Emergency Reference: EC Reset & BIOS
  • EC Reset on freeze: hold power for 20-30 seconds until all LEDs go dark; the console boots only after plugging in the stock Type-C charger.
  • BIOS without keyboard: while powered off, hold RB + RT and press power (works with Fast Boot disabled in BIOS).

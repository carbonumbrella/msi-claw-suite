Game Tuning and FPS

Game Tuning: Upscaling, Frame Gen, and VRR

Practical Lunar Lake tuning: XeSS vs FSR, OptiScaler/LSFG, Low Latency Mode, FPS caps, and custom resolutions.

1. Upscaler: Intel XeSS vs AMD FSR

Always prioritize Intel XeSS: on Lunar Lake (Arc 140V), it executes on dedicated Intel XMX matrix engines (DP4a is only a fallback for GPUs without XMX), yielding sharp geometry without shimmer or ghosting.

Use AMD FSR 2 / 3 only when XeSS is unavailable: general-shader FSR leaves more noticeable temporal ghosting on Arc GPUs.

2. Native Frame Generation: OptiClick and OptiScaler

For single-player titles, OptiClick swaps DLSS/FSR binaries with OptiScaler in one click, enabling Intel XeSS and frame generation (XeFG / FSR FG).

  • Clean HUD & low latency: frames interpolate prior to UI rendering using native engine motion vectors.
  • Real scaling: optical flow overhead trims base rendering by 5:10%. A 45 FPS base outputs 78:82 FPS (~1.75x:1.80x effective).
XeSS vs FSR 4 in OptiScaler: OptiScaler supports FSR 4 on Intel XMX (FSR 4 XMX / Light), but native XeSS stays faster on Lunar Lake: 2+ ms per frame vs 5+ ms for FSR 4 XMX.
Security: never use OptiClick in online games with anti-cheat (Easy Anti-Cheat, BattlEye, Ricochet): replacing dxgi.dll risks bans.

3. External Frame Generation: Lossless Scaling (LSFG)

For games without native upscalers, older ports, and 30:60 FPS-capped emulators, use Lossless Scaling (Steam, LSFG).

With a stable 40:45 FPS baseline, Desktop Duplication capture and LSFG reduce base rendering by 10:15%, producing 70:78 displayed FPS (~1.7x) inside the VRR range.

Criteria OptiClick (OptiScaler) Lossless Scaling (LSFG)
Integration In-engine (motion vector hooks) External Windows capture
HUD Crisp (rendered post-gen) Interpolated with the scene
Input Lag Minimal (native sync) Moderate (capture buffer overhead)
Compatibility Games with DLSS 2+ or FSR 2+ Any windowed game or emulator

4. Input Latency: Low Latency On vs Boost

Low Latency Mode (ClawTweaks and Intel Graphics Command Center) sets the CPU render queue depth:

  • On (baseline): Queue Size = 1; lowers lag with zero extra power draw.
  • On + Boost (AC power): Queue Size = 1 plus locking GPU clock at 1950 MHz; required alongside XeFG, FSR FG, or LSFG.
  • Off: standard 3-frame queue with sluggish response.
On battery: stay on standard On. At 15:17W limits, Boost pulls shared package power away from CPU cores, causing micro-stutters.

5. FPS Capping and Refresh Rates

Do not clamp PL1 wattage while leaving framerates uncapped: set an FPS Cap (ClawTweaks, RTSS, or MSI Center M) so power scales down automatically with flat frametimes.

Safe Caps for 120 Hz VRR:
  • 116 FPS + V-Sync (Blur Busters): 8.62 ms against the 120.0 Hz panel ceiling (8.33 ms) absorbs limiter jitter and prevents VRR dropouts or tearing.
  • 63..116 FPS: locks display inside native 1x VRR above the LFC transition zone.
  • 45..54 FPS: clean 2x LFC doubling (90..108 Hz) safely below the 120 Hz cap.
  • 60 FPS: the stock Intel driver profile (60..120 Hz) clamps the 1x floor at 60 Hz (LFC kicks in below ~60 FPS), making fixed 60 Hz + V-Sync safer without tools; with ArcSyncSwitch (48..120 Hz profile), 60 FPS runs smoothly in native 1x VRR with stats overlays turned off.

Full DisplayID and LFC mechanics: Display & VRR Guide.

  • 120 Hz + VRR (LFC): best for dynamic 3D titles ranging 45:80 FPS.
  • 48 Hz + V-Sync: maximum battery endurance on trips at a steady 48 FPS.

6. 16:10 Render Resolutions

When 1920x1200 falls short, step down gradually (using the two custom handheld-resolution-pack modes) before dropping to 1280x800:

  • 1680x1050 (1050p, standard): -23% GPU shading load.
  • 1600x1000 (1000p, 1.20x, custom pack): -30.5% load, sharp base for upscalers.
  • 1536x960 (960p, 1.25x, custom pack): -36% load, sweet spot for heavy AAA games.
  • 1440x900 (900p, standard): -44% load, suited to battery profiles.
  • 1280x800 (800p, standard): -56% load, maximum battery life.
In ClawTweaks (Display) or Intel Graphics Command Center (Display), enable GPU Scaling and Preserve Aspect Ratio to retain 16:10 geometry.

7. Intel Endurance Gaming on Battery

On battery power, Intel Endurance Gaming in the Arc driver enforces framerate limits automatically:

  • Performance: ~60 FPS cap.
  • Balanced: ~40 FPS cap.
  • Battery Saver: up to 30 FPS.

Hitting a 40 or 60 FPS lock after unplugging is expected Endurance Gaming behavior; plugging AC back in disables it.

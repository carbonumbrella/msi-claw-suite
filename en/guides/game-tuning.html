Game Tuning and FPS

Game Tuning on MSI Claw: Upscaling, Frame Generation, and Input Latency

Practical guide to optimizing game performance on Lunar Lake: choosing between native Intel XeSS and AMD FSR, integrating frame generation pipelines, resolving input lag with Low Latency Mode, stabilizing frametimes, and selecting render resolutions.

Guide Contents:
  • 1. Upscaler Selection: Intel XeSS vs AMD FSR
  • 2. Native Frame Generation: OptiClick and OptiScaler
  • 3. External Frame Generation: Lossless Scaling (LSFG)
  • 4. Input Latency: Low Latency On vs Boost
  • 5. Smoothness Strategy: FPS Capping and Refresh Rates
  • 6. Render Resolutions Without Quality Loss
  • 7. Intel Endurance Gaming Behavior on Battery

1. Upscaler Selection: Intel XeSS vs AMD FSR

Always select Intel XeSS in game graphics settings: on Lunar Lake architecture, it utilizes Arc DP4a vector hardware, providing crisp geometry without shimmering or ghosting trails.

Switch to AMD FSR 2 / 3 only if XeSS is unavailable: on Intel Arc GPUs, FSR computes via general shader calls and often leaves noticeable ghosting behind moving objects.

2. Native Frame Generation: OptiClick and OptiScaler

For single-player titles, use OptiClick: this utility replaces DLSS/FSR binaries with open-source OptiScaler in one click, enabling native Intel XeSS and frame generation (XeFG / FSR FG).

  • Clean HUD: Intermediate frames are interpolated inside the engine pipeline before drawing interface elements. Crosshairs, text, and maps do not double.
  • Minimal Latency: Direct motion vector access minimizes input lag.

Effective Scaling: Frame generation does not deliver a pure 2.0x doubling. Computing intermediate frames and motion vectors reduces native rasterization speed by roughly 5:10%. An initial 45 FPS translates into approximately 78:82 displayed frames (effective scaling of ~1.75x:1.80x).

XeSS vs FSR 4 in OptiScaler: Recent OptiScaler builds support executing FSR 4 models on Intel XMX matrix cores (FSR 4 XMX and FSR 4 Light). At the moment on Lunar Lake architecture, native XeSS remains the better choice: FSR 4 XMX inference takes 5+ ms per frame versus 2+ ms for XeSS, consuming too large a portion of the handheld frame budget.
Security: Never use OptiClick in multiplayer games protected by anti-cheat (Easy Anti-Cheat, BattlEye, Ricochet): swapping dxgi.dll triggers account bans.

3. External Frame Generation: Lossless Scaling (LSFG)

For games lacking native temporal upscalers, retro ports, and emulators locked to 30:60 FPS, use the Lossless Scaling utility (Steam) with the LSFG algorithm.

Baseline Requirement: Stable 40:45 FPS in the base game. Window capture and LSFG interpolation lower base rasterization by 10:15%, so an initial 40:45 FPS translates into roughly 70:78 displayed frames (effective ~1.7x scaling), falling squarely into the panel VRR range.

Criteria OptiClick (OptiScaler) Lossless Scaling (LSFG)
Integration Point Inside engine pipeline (hooks into motion vectors) External Windows window capture
User Interface (HUD) Clear: HUD renders after frame generation HUD and text interpolate along with full scene
Input Latency Minimal (native queue synchronization) Moderate (window capture buffering overhead)
Compatibility Titles supporting DLSS 2+ or FSR 2+ Any windowed game, retro port, or emulator

4. Input Latency: Low Latency On vs Boost

The Low Latency Mode (Anti-Lag) setting is available directly inside the ClawTweaks widget as well as Intel Graphics Command Center. It controls CPU frame queue depth:

  • Setting On (Recommended Baseline): Limits frame queue depth to exactly 1 (Queue Size = 1). Minimizes input lag without unnecessary power draw.
  • Setting On + Boost (AC Power Only): Maintains 1-frame queue depth and locks GPU core clock at its 1950 MHz ceiling. Enable when frame generation is active (XeFG, FSR FG, Lossless Scaling) to offset interpolation latency.
  • Setting Off: Standard 3-frame queue with higher input latency.
Battery Play: Use only standard On mode. On low TDP limits (15:17W), Boost pulls shared power toward the GPU, starving CPU cores and provoking micro-stutters.

5. Smoothness Strategy: FPS Capping and Refresh Rates

Do not throttle CPU package power (PL1) while leaving framerate floating. Instead, lock a strict framerate cap (FPS Cap) via ClawTweaks, RTSS, or MSI Center M. The processor will automatically scale power down to the minimum required, eliminating frametime spikes.

Bypassing the LFC Boundary Zone (56:62 FPS): On a 120 Hz VRR panel, avoid setting caps at 58:60 FPS. A lack of driver hysteresis at the 60 Hz threshold causes the LFC multiplier to rapidly oscillate between 1x (60 Hz) and 2x (116:120 Hz), causing micro-tearing:
  • Cap at 63 FPS (or 64:65): Keeps the display in stable native 1x VRR without engaging doubling.
  • Cap at 50 FPS (or 45:52): Locks into stable 2x LFC at 100 Hz with comfortable headroom below the 120 Hz ceiling.
  • If you require exact 60 FPS: Switch the panel to fixed 60 Hz in the ClawTweaks Display tab and enable V-Sync.

Display refresh rate deployment scenarios:

  • 120 Hz + VRR (LFC): Primary choice for 3D games fluctuating between 45 and 80 FPS. Low Framerate Compensation duplicates refresh cycles to maintain smooth output without tearing.
  • 48 Hz + V-Sync: Maximum battery endurance mode for travel. Reduces panel and controller power, while 48 FPS looks noticeably smoother than 30 FPS.

6. Render Resolutions Without Quality Loss

If a game struggles at native 1920x1200 (16:10), avoid blurry 1280x800. Use intermediate 16:10 resolutions from handheld-resolution-pack:

  • 1600x1000 (1000p, 1.20x scale): Reduces GPU shading load by 31% compared to 1200p while preserving clean pixel grids for upscalers.
  • 1536x960 (960p, 1.25x scale): Reduces GPU load by 36%, ideal for demanding AAA titles.
In the ClawTweaks Display tab (or Intel Graphics Command Center Display tab), configure: GPU Scaling and Preserve Aspect Ratio to prevent image stretching and preserve accurate 16:10 geometry.

7. Intel Endurance Gaming Behavior on Battery

The Intel Endurance Gaming feature in the Arc graphics driver automatically caps framerates when external power is unplugged to protect the battery:

  • Performance: caps near 60 FPS.
  • Balanced: caps near 40 FPS.
  • Battery Saver: caps at 30 FPS.

If disconnecting external power locks framerate to 40 or 60 FPS, this is normal Endurance Gaming behavior. Reconnecting AC power automatically suspends the feature.

Memory Optimization, Pagefile, and System Stability

Unified LPDDR5x memory, static 16 GB pagefile against DirectX crashes, Windows 11 services, EC Reset, and BIOS access.

Devices: MSI Claw 8 AI+, Claw 7 AI+, Claw A1M
Memory: 32 GB LPDDR5x
Reading Time: 7 minutes

1. Unified LPDDR5x Memory

Intel Core Ultra 200V (Lunar Lake) uses Memory on Package (MoP): LPDDR5x dies (up to 8533 MT/s) sit directly on the processor substrate and share bandwidth dynamically across CPU cores, the Intel Arc GPU, and the NPU.

2. GPU Memory Allocation in Windows and Intel Arc

BIOS offers no UMA Frame Buffer switch: under WDDM, Windows assigns up to 50% of system RAM as 16.0 GB Shared GPU Memory on a 32 GB device (Intel Graphics Software also exposes Shared GPU Memory Override defaulting to 57% ~18.2 GB). Modern games need no BIOS overrides.

Check live allocation in Task Manager (Ctrl + Shift + Esc) → Performance → GPU → Shared GPU Memory (16.0 GB default).

3. Fixed 16 GB Pagefile

Once graphics workloads claim 8..16 GB, remaining system RAM shrinks. With a System Managed dynamic pagefile, Windows expands the SSD paging file mid-game, causing I/O latency spikes.

Root Cause of DirectX (DXGI) Crashes: pagefile expansion stalls the render pipeline past the GPU timeout window, triggering DXGI_ERROR_DEVICE_REMOVED, DXGI_ERROR_DEVICE_HUNG, or Out of Video Memory.

Static 16384 MB Lock (Manual or Optimize-Handheld)

The Memory category in Optimize-Handheld locks a static 16 GB (16384 MB) pagefile and disables shutdown zeroing automatically.

Manual setup in elevated PowerShell:

Set-CimInstance -Query "Select * from Win32_PageFileSetting where Name like 'C:%'" -Property @{InitialSize = 16384; MaximumSize = 16384}

Via Windows GUI:

  1. Press Win + R, run sysdm.cpl → Advanced → Performance (Settings) → Advanced → Virtual memory (Change).
  2. Uncheck automatic management, pick C:, set Initial and Maximum size to 16384, click Set → OK, and reboot.
Every 300:500 MB consumed by heavy background apps cuts GPU headroom and triggers paging. See Software Choice →.

4. Core Isolation (HVCI), Audio Services, and BitLocker

  • Core Isolation (HVCI): if tuning apps fail to access MSR/TDP drivers, open Windows Security → Device security → Core isolation details, disable Memory integrity, and reboot.
  • Background Audio Effects: the optional VendorAudio category in Optimize-Handheld disables third-party audio services DTS (DtsApo4Service) and MSI intelliGo (IgoAudioService) (~90 MB RAM and background CPU cycles) while leaving the core Realtek audio driver untouched.
  • BitLocker Device Encryption: enabled by default in Windows 11, adding constant SSD and CPU overhead during asset streaming. Disable via option 6 in Optimize-Handheld or Settings → Privacy & security → Device encryption.

5. Embedded Controller (EC) Reset and UEFI Access

Hardware EC Reset (for freezes or black screens):
  1. Hold the power button for 20-30 seconds until all LEDs and thumbstick rings turn off completely.
  2. The motherboard enters Shipping Mode: pressing power on battery will not turn it on.
  3. Plug in the factory Type-C charger and press power once to boot normally.

Entering BIOS / UEFI:

  • Gamepad shortcut: while powered off, hold RB + RT and press power (works with Fast Boot disabled in BIOS).
  • Windows UI: Settings → System → Recovery → Advanced startup → Restart now → Troubleshoot → Advanced options → UEFI Firmware Settings.
  • External keyboard: tap Del or F2 during boot.

6. Hidden Service BIOS Menu

Right Ctrl + Right Shift + Left Alt + F2
  • Wired USB keyboard (or 2.4 GHz dongle) only: Bluetooth keyboards do not operate before Windows boots.
  • Bootloop risk: changing hidden memory timings or manual VRAM limits on Lunar Lake brings zero gains and frequently causes unrecoverable bootloops; Intel microcode and the Arc driver manage memory allocation automatically.
